Open-source developer infrastructure

MCP / C++ source navigation

mcp-cpp-project-indexer

A deterministic C++ source-range indexer for MCP-based AI code navigation. It helps tool-using AI systems locate symbols, data declarations, C++20 modules, include relationships and exact source ranges before making source-grounded claims.

Core principle: Find code. Read code. Do not guess code.

  • Designed for metadata-first navigation and exact source reads.
  • Supports large C++ projects, including C++20 module-heavy codebases.
  • Provides MCP tools, HTTP server mode, watcher updates and a terminal management UI.
  • Built to reduce broad file scanning, tool loops and unsupported semantic assumptions.
